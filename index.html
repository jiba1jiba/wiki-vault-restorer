VaultRestore

Плагин для Paper и Purpur 26.1.2: восстановление хранилищ (vault) в Trial Chamber с настраиваемым таймером.

Обзор Установка и сборка Как работает Меню Команды и конфиг Вопросы

Обзор

После того как игрок открыл хранилище ключом, плагин через заданное число секунд снова даёт ему такую возможность. Над хранилищем всё это время висит надпись с оставшимся временем, а когда время выходит, надпись просто пропадает.

  • Хранилища: и обычные, и зловещие (ominous).
  • Таймер: задаётся в секундах через меню в игре или командой, хранится в config.yml.
  • Надпись: видна только тому игроку, чей это таймер, и только рядом с хранилищем (до 48 блоков).
  • Версия: Paper или Purpur 26.1.2, Java 25. Плагин использует только API Paper.
Код написан по документации API Paper, но ещё не собирался и не проверялся на живом сервере. Если при сборке или на сервере что-то не работает, пришлите текст ошибки.

Установка и сборка

Готового jar нет, плагин собирается из исходников (VaultRestore-source.zip).

  1. Установите JDK 25, например Temurin.
  2. Распакуйте архив и в папке проекта выполните gradle build.
  3. Положите build/libs/VaultRestore-1.0.0.jar в папку plugins/ сервера.
  4. Перезапустите сервер. Файл plugins/VaultRestore/config.yml создастся при первом запуске.

Зависимость в build.gradle.kts: io.papermc.paper:paper-api:26.1.2.build.+ из репозитория https://repo.papermc.io/repository/maven-public/.

Как это работает

Таймер запускается отдельно для каждой пары «игрок + хранилище», а не для всего хранилища сразу.

  1. Игрок кликает правой кнопкой по хранилищу.
  2. Через 2 тика плагин проверяет, записало ли хранилище игрока в список получивших награду. Если да, запоминается момент открытия, и над хранилищем появляется надпись «Восстановление: 12:34».
  3. Раз в секунду плагин обновляет надписи и проверяет таймеры. Когда время вышло, игрок удаляется из списка получивших награду, а надпись исчезает.
  • Неудачный клик (не тот ключ, хранилище уже открыто игроком) таймер не запускает.
  • Надпись показывается, пока игрок онлайн, находится в том же мире в пределах 48 блоков и чанк загружен. Если игрок ушёл далеко или вышел, надпись убирается, а таймер продолжает идти.
  • Формат времени: М:СС, при часах Ч:ММ:СС, при суточных значениях дни, часы, минуты.
  • Выключенный плагин: при enabled: false новые таймеры не создаются, старые не срабатывают, надписи убираются.
  • Незагруженный мир или чанк: запись ждёт загрузки и только потом восстанавливает хранилище.
  • Разрушенное хранилище: запись удаляется.
  • Перезапуск сервера: таймеры сохраняются в plugins/VaultRestore/data.yml (раз в 30 секунд и при выключении), отсчёт идёт по реальному времени. Надписи на диск не пишутся и появляются заново.
  • Смена таймера: новое значение действует и для уже запущенных таймеров.

Меню настройки

Открывается командой /vaultrestore, доступно только игрокам с правом vaultrestore.admin. Любое изменение сразу сохраняется в config.yml.

КнопкаДействие
Красные блоки: -1000, -100, -10, -1 секУменьшают таймер на указанное число секунд
Часы в центреПоказывают текущий таймер в секундах и в днях, часах, минутах
Зелёные блоки: +1, +10, +100, +1000 секУвеличивают таймер на указанное число секунд
КрасительВключает или выключает восстановление
ТабличкаВключает или выключает надпись над хранилищем
БарьерСбрасывает таймер на 1800 секунд

Таймер ограничен диапазоном от 1 секунды до 31 536 000 секунд (один год). Предметы из меню забрать нельзя.

Команды и конфиг

Основная команда /vaultrestore (алиас /vrestore). Без аргументов открывает меню. Все подкоманды требуют права vaultrestore.admin, по умолчанию оно есть у операторов.

КомандаДействие
/vaultrestore menuОткрыть меню (только для игроков)
/vaultrestore set <секунды>Задать таймер числом, значение приводится к диапазону 1–31 536 000
/vaultrestore toggleВключить или выключить восстановление
/vaultrestore statusПоказать таймер, состояние и число ожидающих записей
/vaultrestore reloadПеречитать config.yml

Файл plugins/VaultRestore/config.yml:

# Через сколько секунд хранилище снова станет доступно игроку, который его открыл
delay-seconds: 1800
# Включено ли восстановление
enabled: true
# Показывать над хранилищем надпись с оставшимся временем (видна только игроку, чей это таймер)
show-timer: true

Файл data.yml в той же папке служебный: в нём хранятся запущенные таймеры, вручную его править не нужно.

Частые вопросы и ограничения

Восстанавливается ли хранилище для всех игроков сразу?
Нет. Плагин убирает из списка только того игрока, чей таймер истёк. Остальные получают доступ в свой срок.
Видят ли надпись другие игроки?
Нет. Надпись создаётся невидимой для всех и показывается только владельцу таймера, у каждого игрока своя.
Что происходит с надписью, когда время вышло?
Она удаляется. Хранилище становится доступным игроку, и над ним ничего не остаётся.
Что с хранилищами, которые открыли до установки плагина?
Плагин их не знает: таймер запускается только по клику игрока при включённом плагине. Такие хранилища не восстановятся.
Восстанавливает ли плагин генераторы (trial spawners)?
Нет, только хранилища. У спавнеров своя механика перезарядки.
Считается ли время, пока чанк выгружен?
Да, отсчёт идёт по реальному времени. Если срок истёк, восстановление произойдёт после загрузки чанка.
Работает ли плагин на Folia?
Нет, он использует обычный планировщик Bukkit и рассчитан на Paper и Purpur.
